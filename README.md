## 👨‍💻 About Me

I'm a **Flutter Developer** and **Mobile Application Engineer** based in **Cairo, Egypt 🇪🇬**, with a Bachelor's degree in Information Systems from Benha University (Faculty of Computers & AI, class of 2026).

I build cross-platform apps using **Flutter, Dart, and Firebase**, with a strong focus on **Clean Architecture**, **BLoC/Cubit** state management, and **REST API** integration. I've delivered multiple production-ready apps, from an AI-powered scholarship platform to a full e-commerce app, and I enjoy working in teams.

- 🔭 Looking for a **Junior Flutter Developer** opportunity
- 🌱 Improving my skills in testing and scalable architecture
- 💬 Ask me about Flutter, Dart, Firebase, or state management
- 🤝 Led a team of developers during my NTI training

## 🚀 Featured Projects

### 🎓 [Scholara (GrantGo)](https://github.com/karimashraf-dev/Scholara) — AI-Powered Scholarship Discovery App

A cross-platform Flutter app that helps students discover scholarships using AI.

- 🔌 Integrated a **Node.js/MongoDB** backend through **15+ REST endpoints** using Dio
- 🔐 Implemented **JWT authentication** with persistent sessions and an **OTP email-verification** flow
- 🤖 Built an **AI recommendation engine** (TF-IDF & Cosine Similarity) that surfaces the top 3 scholarship matches per user
- 📄 Developed **CV upload and AI analysis** with real-time status polling
- 🧩 Refactored all Cubits onto a single shared Dio instance, standardizing error handling across 10+ modules

`Flutter` `Dart` `BLoC/Cubit` `Dio` `Node.js` `MongoDB` `JWT` `TF-IDF`

<br/>

### 🛍️ [Shopping App](https://github.com/karimashraf-dev/Shopping-App) — E-Commerce Mobile App (Team Lead)

An 8-screen e-commerce app built during the NTI training, where I led a team of developers.

- 🛒 Core features: authentication, products from a deployed REST API, categories, search, product details, cart, favorites, and account management
- 🏗️ Architected with **Clean Architecture + BLoC**: shared core module and feature folders split into data, domain, and presentation layers
- 💉 Used **Injectable** for dependency injection and **Flutter Secure Storage** for secure on-device data
- 🔀 Managed version control with Git/GitHub and resolved merge conflicts to keep the codebase stable

`Flutter` `Dart` `BLoC` `Clean Architecture` `REST API`
